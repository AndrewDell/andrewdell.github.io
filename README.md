# andrewdell.github.io

Personal site of Andrew Dell, Support Operations Architect. Jekyll on GitHub Pages (branch build, `main`, root).

- Content lives in `_data/` and the `_playbooks/`, `_skills/`, `_trail/` collections.
- Styles: `assets/css/site.css` (design tokens, light/dark). Script: `assets/js/site.js` (progressive enhancement only).
- Agent files: `llms.txt`, `llms-full.txt`, `agents.md`, `robots.txt` (all generated).
- Licenses: playbooks CC BY 4.0; Claude skill files MIT.

Local preview: `bundle install` then `bundle exec jekyll serve`.
